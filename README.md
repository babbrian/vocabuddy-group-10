## 專案簡介

VocaBuddy 是專為英文單字學習打造的 Python 工具，提供單字整理、分類管理與隨堂測驗功能，讓複習更具系統性。本專案支援 Google Colab 雲端環境，使用者無需在本地端安裝複雜軟體，即可開箱即用。

- m1stzy：添加隨機選單字卡功能

## 新增的單字與功能

- 預設單字包：
    - SCC: 強連通分量
    - BCC: 雙聯通分量
    - DP: 動態規劃
    - BIT: 二元索引樹
    - DSU: 並查集
- 可自行輸入英文單字及中文解釋建立字卡，支援翻面、切換、刪除及匯入／匯出。
- 「隨機抽卡」功能，會抽出不同於目前的字卡；至少兩張卡才能使用。
- 一次刪除全部單字
- 重置熟悉度
- 根據單字的熟悉度進行帶權隨機功能
- 10秒測驗
